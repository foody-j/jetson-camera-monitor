# 로봇 PC MQTT 파서 가이드

## 개요
로봇 PC에서 보내는 상태 메시지를 Jetson1, Jetson2에서 수신하고 파싱하는 기능 추가.

## 변경된 파일

| 파일 | 변경 내용 |
|------|----------|
| `jetson1_monitoring/JETSON1_INTEGRATED.py` | 로봇 상태 파서 추가 |
| `jetson2_frying_ai/JETSON2_INTEGRATED.py` | 로봇 상태 파서 추가 |

## 구독 토픽

```
HR/Status
```

- 실제 토픽: `HR/Status`
- config에서 변경 가능: `mqtt_topic_robot_status`

## 로봇 메시지 형식 (예상)

```json
{
  "DeviceNum": "0",
  "PTNum": "0",
  "Potstatus": {
    "PT_Power": "True",
    "PT_Level": 6,
    "PT_Mode": 1,
    "PT_Temp": 180.5,
    "PT_Sensor": "True",
    "RT_Speed": 0,
    "RT_Dir": 0,
    "RT_Run": 0
  },
  "RBstatus": "연결상태(구동중)",
  "TotalTime": "00:14:39",
  "TargetTime": "5분",
  "RunningTime": "0분 8초",
  "Mode": "시간설정",
  "ProcessType": "조리",
  "NowRecipe": "제육볶음"
}
```

## 필드 설명

| 필드 | 설명 |
|------|------|
| `DeviceNum` | 솥 위치 (0: 왼쪽, 1: 오른쪽) |
| `PTNum` | 솥 번호 (0번솥, 1번솥) |
| `ProcessType` | 투입 / 조리 / 배출 |
| `NowRecipe` | 현재 레시피명 |
| `PT_Temp` | 솥 온도 |
| `RunningTime` | 조리 경과 시간 |

## 로그 출력

메시지 수신 시 아래와 같이 로그 출력:

```
[로봇상태] POT0 | 조리 | 제육볶음 | 온도:180.5 | 0분 8초
```

## 현장 테스트 방법

### 1. 토픽 확인
```bash
# 모든 토픽 구독해서 확인
python3 -c "
import paho.mqtt.client as mqtt

def on_message(client, userdata, msg):
    print(f'[{msg.topic}] {msg.payload.decode()}')

client = mqtt.Client()
client.on_message = on_message
client.connect('브로커IP', 1883)
client.subscribe('#')
client.loop_forever()
"
```

### 2. 토픽 이름 다를 경우
config.json에서 수정:
```json
{
  "mqtt_topic_robot_status": "HR/Status"
}
```
