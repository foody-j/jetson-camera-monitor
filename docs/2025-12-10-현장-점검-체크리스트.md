## 5. 진동센서 디버깅 (핵심!)

### 5-1. 현재 상태 확인
```bash
cd ~/jetson-food-ai
python3 debug_vibration.py
```
확인할 것:
- [ ] 통신 되는지 (응답 있는지)
- [ ] ACC 값 나오는지 (예: 1.xxx)
- [ ] VEL/DISP/FREQ가 전부 0인지

### 5-2. 설정 확인 + 복구 (핵심 스크립트!)
```bash
python3 fix_vibration_sensor.py
```

**이 스크립트가 하는 일:**
1. 현재 설정 읽기 (0x63, 0x64, 0x65)
2. 현재 VEL/DISP 데이터 확인
3. **검출주기(0x65)를 50Hz로 설정** ← 엔터 누르면 실행
4. 설정 후 데이터 다시 확인

**핵심 레지스터:**
- `0x63` - 차단 주파수 1
- `0x64` - 차단 주파수 2
- `0x65` - **검출 주기** ← 이게 0이면 VEL/DISP 출력 안 됨!

### 5-4. 센서 개별 테스트 (시간 되면)
- [ ] 0x50만 연결해서 테스트
- [ ] 0x51만 연결해서 테스트
- [ ] 0x52만 연결해서 테스트

## 6. 진동센서 문제 요약 (제조사 문의용)

**현상:**
- 통신 OK, ACC는 나옴
- VEL/DISP/FREQ 전부 0

**타임라인:**
- 12V → 24V 변경
- 변경 직후: 정상 작동
- 1주일 후: VEL/DISP 안 나옴

**의심 원인:**
1. 24V 전원으로 센서 설정 초기화됨
2. 검출 주기(0x65) 레지스터가 0으로 리셋됨
3. 센서 펌웨어 문제
